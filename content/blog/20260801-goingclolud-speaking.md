GC x AWS
當初 Alex 提到有這個機會的時候我沒想太多就答應了，因為分享的內容切合我有興趣且熟悉的領域，而且我認為這對我來說會是一個很好的挑戰，感謝 Going Cloud 提供機會讓我可以向與會嘉賓介紹自己對於 Coding Agent 的使用經驗以及對於產業的影響。

藉由這次機會也讓我重新審視目前對於 Agentic Coding 的認知與理解，找了非常多 Anthropic 出品的講座與文章，整合各路大神的見解並思考自己是如何思考與解決問題的。好好的整理 & 重新設計自己使用 Claude Code 的 Harness 設定，讓 Coding Agent 跟 LLM Wiki 可以有更好的整合性，改善我使用上的流暢程度以及降低認知負荷。

在現今 AI 技術不斷進步、不斷迭代的狀況下，每隔一段時間就有新的 Protocol、新的名詞或概念被提出，但只要載體還是 LLM 就始終離不開所謂 `Context Engineering` ，我認為最好的設定絕對不是盲信與照抄整包 & 一鍵式的完整設定或工具，而是需要確保自己讀過並了解每個想要導入的工作流程、Skills 等框架與工具為何要這樣設計，並且按需引用來打造出最符合自身需求與思考迴路的 Agent 工作流。

再次感謝 GC 與這次籌備組的一切支援，讓活動與講座內容一切順利！
