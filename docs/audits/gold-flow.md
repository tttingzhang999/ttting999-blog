# Gold-line continuity audit — 2026-09-12

Scope: read-only audit of the Nuxt integration at http://127.0.0.1:3000/en. No animation implementation changed. Browser: Chrome, 1440×900. Observed custom events and computed opacity every 80ms during A→B→C→B and keyboard article focus. Other edge cases below are identified from source and marked accordingly.

## Findings

1. **Confirmed, high — scene geometry teleports.** `runtime.ts` emits `scenevisual` only from `sync`/`afterLoad`; the fullPage move lasts 950ms. `filament.ts` handles it with `updateGeometry(false)`, replacing every control point immediately. The old fixed line stays put while the content scrolls, then jumps to the destination composition. Applies in both directions and to direct navigation.
2. **Confirmed, high — A/B transition uses two unrelated line renderers.** The fixed Canvas handles settled A/B/C curves; the section-local SVG handles the article timeline. `journalintrostart` hides Canvas after it has already switched to B geometry. The SVG begins from its own midpoint and resets progress to zero. They share no current position, tangent, velocity, or light phase. The 400ms opacity fade can briefly overlap unrelated shapes.
3. **Confirmed, high — a visible absence of line at the timeline exit.** With seven articles, SVG fade starts at 3.75s and ends at 4.40s. Completion restores Canvas only at about 5.50s. Browser samples showed SVG opacity 0 and Canvas opacity 0 from about t=5.44s to 6.48s measured from the A→B click. Canvas then fades back in over 400ms at the article geometry. Thus there is roughly 1.1s of no line even before the reappearance fade.
4. **Confirmed, high — completion, cancellation and focus share a destructive reset.** `stopIntro` always emits `journalintrostop`, even without a running intro. That handler kills flight, sets progress=1/strength=0 and replaces geometry without interpolation. Focus test recorded `articlevisual(index=4)` then `journalintrostop` one millisecond later: the new hover/focus morph is immediately killed. On leaving B mid-intro, its static line can reappear before the outgoing fullPage movement completes.
5. **Source-confirmed — every light flight restarts at its origin.** `launch()` kills the old flight and sets progress=0/strength=1 on scene changes and project selection. Reverse navigation is not represented in the visual event. This resets the light's position and velocity instead of carrying its phase forward.
6. **Source-confirmed — fast hover has position continuity but poor velocity continuity.** `updateGeometry()` uses the current path as origin, which is correct for position continuity, but every hover kills and restarts a 1.35s power3.inOut ease. Rapid target changes repeatedly decelerate/re-accelerate and can lag behind the pointer. This is distinct from the instant replacement caused by keyboard focus.
7. **Source-confirmed — viewport/document coordinate mismatch in native reading mode.** Canvas is fixed; `contentBox` returns section-local y (rect.y minus section.y). This assumes the active section top is 0, which holds after desktop snap but not during movement or native scroll. The renderer does not update on ordinary native scroll. Article/project pointers can be vertically detached from their content. Scene selection via IntersectionObserver also switches geometry immediately.
8. **Source-confirmed — environment changes reset geometry and light.** Resize/visibility use `settle`, setting progress=1, strength=0, cursor=0 and replacing paths. Runtime resize also cancels the intro, even if the scene-mode breakpoint did not change. Font readiness directly recomputes geometry. Reduced-motion's deliberate direct settling should remain supported; ordinary visible resize should preserve continuity where possible.
9. **Source-confirmed — curve construction/materials do not guarantee a seamless join.** Canvas uses three strands and offset threads; SVG uses one uniform line and different glow styling. Canvas A/B/C curves have independently assigned directions and control points. The SVG's adjacent cubic controls use vertical endpoint tangents; when its sinusoidal height changes slope sign, adjacent tangents can reverse. None of these pieces currently enforce matching endpoint/tangent/speed during handoff.
10. **Source-confirmed — initial deep links and idle phase are disconnected.** Canvas initializes to A and launches before runtime selects #writing/#practice. Flights finish and fade out rather than maintaining a shared phase; only C retains a static endpoint bead. A's pointer deformation is toggled by the scene index, adding another instantaneous shape change on exit.

## Existing verification gap
Previous checks correctly tested triggering, completion, data, responsive fallback and route cleanup. They did not measure per-frame displacement, shared line visibility, tangent continuity, or interruption continuity. Passing those checks did not establish fluid gold-line motion.

## Recommended repair contract
- Keep each scene's independently designed target composition, but drive transitions through one persistent viewport-level line state and one visual owner.
- Carry current geometry, endpoint/tangent, light progress, visibility and velocity forward. Targets change; rendered state is not reset to each scene's initial frame.
- Start the scene bridge at fullPage onLeave and coordinate it with the 950ms page movement. Reverse/direct navigation and interruptions begin at the current rendered state.
- Preserve the approved scan choreography: A curves toward the horizontal timeline; the final lit position then flows to the latest article pointer. Avoid an opacity-only handoff or a dark interval.
- Give completion, skip, navigation cancellation, keyboard focus, resize and reduced motion separate semantics. Normal focus must not invoke intro teardown.
- Measure article/project anchors in viewport coordinates, including native scroll. Maintain steady target tracking with a shorter response and velocity continuity.
- Validate A↔B, B↔C, A↔C, skip/leave at several intro times, rapid hover/focus/project selection, deep links, browser history, resize and visibility return. For normal animated mode, verify no unexplained line disappearance and no single-frame geometry/phase reset; retain reduced-motion exceptions.

Recommended implementation order: shared renderer/state and event semantics → A/scan/B bridge → reverse/direct navigation → hover/focus and responsive tracking → frame-level regression checks. Keep the selected scan design and fullPage navigation.

## Repair implemented — 2026-09-12
- Replaced the disconnected SVG/Canvas handoff with a single persistent Canvas. The scan timeline now animates metadata and supplies progress to the same curve renderer.
- All compositions are sampled onto the same 101-point representation. Critically damped motion preserves position and velocity on retargeting; the light also retains its phase instead of restarting. Idle restart resets elapsed-time bookkeeping, not geometry.
- Scene bridges begin in fullPage onLeave. Completion only changes the target toward the article; outgoing navigation cancels metadata without briefly restoring B. Keyboard focus no longer triggers teardown when no intro is running.
- Native mode uses viewport anchor positions and refreshes on scroll. Resize/font changes retarget existing points; visibility pauses drawing without discarding the curve. Reduced motion intentionally settles directly.
- Removed unused SVG line styles and the opacity handoff. The current section compositions and selected horizontal metadata scan are retained.

Validation: 4 unit tests pass (article projection and motion integration, 100% coverage of those two pure modules); 6 Chrome browser tests pass against the production build. New browser regression captures real Canvas strokes on animation frames across A→scan→B, B→C, C→A, project selection, keyboard focus, and skip, verifying full Canvas opacity and bounding inter-frame curve displacement. The regression failed against the old build on Canvas invisibility. The first repaired run exposed overly fast distant-scene movement; response frequency and idle restart timing were corrected before the final pass. Existing route/mobile/reduced-motion/locale/resize tests also pass. Build passes. Global typecheck still reports the same unrelated 26 existing diagnostics; no new gold-flow module diagnostics remain. Preview refreshed on localhost:3000; no deployment or push.
