# 首頁文字精修

依九則瀏覽器標註，移除首頁職稱、副標、介紹段落，文章區介紹與篇數，以及聯絡邀請。最近文章入口改為「最近的文章」，履歷入口改為「瀏覽完整履歷」。作品區標題提供選項後再依選擇更新。

共用版型的區塊刪除套用三種語言，入口翻譯同步調整。保留入口原有位置，驗證首頁導覽、六篇文章、語系與行動版。

## 刪減後的版面調整

作品區標題採用「從想法，到實作。」。

沿用現有色彩與字型，以大字標題、光線路徑與留白維持首頁識別。色彩使用紙色 #f3f0e8、墨色 #181a1b、琥珀 #94601b、鼠尾草 #52674f、次要文字 #64655f；暗色沿用既有 tokens。字型為 DM Sans 與 Noto Sans TC，大標使用既有字型與字重。

三個畫面皆使用同一左右邊界與內容頂線。首屏採姓名、大標、文章入口的三列自然流向。文章區左側標題及入口頂端對齊右側清單，取消逐篇左右錯位。作品區保留左右切換與內容，社群入口接續右側說明欄。

桌面格局草圖

```text
姓名                  文章區標題    最近文章
    Plan.             文章索引      文章清單
      Execute.
               最近文章

作品區標題                     完整履歷
作品切換清單                   作品說明
                               社群與所有作品
```

手機版採單欄，首屏高度隨視窗與內容調整，文章與作品區移除固定最低高度。閱讀模式縮短上下間距，讓刪除後的內容自然銜接。延續現有首頁識別，排版只依剩餘內容重新分配空間。

以桌面 1440×900、目前預覽 898×751、手機 390×844 檢查三個畫面及深色模式，並跑首頁互動測試與型別檢查。

## 各裝置整頁切換

使用既有 fullPage.js，移除桌面寬高門檻，各裝置均固定在三個區段之間切換。啟用 scrollOverflow，超過畫面高度的內容在該區段內捲動，到底後才進入下一區。保留減少動態效果的原生閱讀模式。

沿用現有 950ms 與 cubic-bezier(.76,0,.24,1) 切換節奏。手機直接顯示文章清單，沿用原本只在較大畫面播放的文章介紹動畫。手機底部只保留頁碼與上下頁操作，避免擠壓內容。新增小視窗的滾輪切換與區段對齊回歸測試。

## 依實際空間決定文章篇數

首頁文章區最多顯示最新六篇，依文章實際換行高度、區段標題、頁首與底部操作預留空間決定能放下的完整篇數。視窗縮放、文字與字型尺寸改變時重新量測。文章區停用區內捲動，查看更多仍由「瀏覽所有文章」進入索引。文章介紹動畫也只使用畫面中可顯示的文章。

無 JavaScript 的閱讀備援保留完整六篇。以手機、平板、桌面及較矮手機視窗驗證，確認文章由最新開始顯示且區段沒有溢出。

## 縮短文章介紹動畫

動畫使用實際可見篇數計算掃描時間，掃描 0.8–1.5 秒，配合 0.2 秒退場與 0.3 秒清單顯示，總長約 1.45–2.15 秒。六篇時由原先約 5.5 秒縮短至約 2.15 秒，保留略過按鈕與手機直接顯示清單的行為。
